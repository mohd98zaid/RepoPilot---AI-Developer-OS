# RepoPilot — AI Developer OS Plan Pack

This package contains a master plan and six supporting implementation documents.

- `07_COMPLETE_FEATURE_CATALOG.md` — standalone complete feature inventory, including MVP checklist and non-goals.
- `00_MASTER_PLAN.md` — product and engineering blueprint
- `01_PRD.md` — product requirements
- `02_ARCHITECTURE.md` — system architecture
- `03_TECH_STACK_AND_FREE_MODELS.md` — free/open-source technology strategy
- `04_SECURITY_THREAT_MODEL.md` — security boundaries and threat tests
- `05_EVALUATION_AND_TEST_PLAN.md` — benchmark and testing plan
- `06_IMPLEMENTATION_BACKLOG.md` — actionable development checklist

## Cost/licensing caveat
The plan avoids mandatory paid SaaS dependencies. Open-source software can still require hardware, electricity, setup, and maintenance. Model weights and optional plugins have separate licenses; audit each license and verify current terms before use.
